# trellis_text — TRELLIS native text→3D

**Method**: Microsoft TRELLIS, text-conditioned model `microsoft/TRELLIS-text-xlarge`
(`TrellisTextTo3DPipeline`), prompt = the asset `description` verbatim (no template).

## Version / environment
- Code: official repo `https://github.com/microsoft/TRELLIS` cloned to
  `methods/trellis_text/TRELLIS`, commit `442aa1e1afb9014e80681d3bf604e8d728a86ee7`
  (2025-11-05; EmbodiedGen's `thirdparty/TRELLIS` submodule is from Dec 2024 and has no text pipeline).
- Weights (HF, cached in `RoomGenBench/.cache/huggingface`): `microsoft/TRELLIS-text-xlarge`
  (sparse-structure + SLat flow models), decoders from `JeffreyXiang/TRELLIS-image-large`
  (as referenced by its `pipeline.json`), text encoder `openai/clip-vit-large-patch14`.
- Conda env `rgb_embodiedgen` (shared with `embodiedgen_v2`; python 3.10.13, torch 2.8.0+cu126,
  xformers 0.0.32.post2, spconv-cu126, kaolin 0.18.0, nvdiffrast 0.3.3, mip-splatting
  diff-gaussian-rasterization; CUDA extensions built for sm_86 + sm_90). See
  `results/embodiedgen_v2/README.md` for how the env was built. `ATTN_BACKEND=xformers`
  (flash-attn not installed; numerically equivalent attention), `SPCONV_ALGO=native`.

## Settings (all TRELLIS defaults unless noted)
- `pipeline.run(prompt, seed=0, formats=["mesh","gaussian"])` — sampler params from the model's
  `pipeline.json`: both stages 25 Euler steps, cfg 7.5, cfg interval [0.5, 0.95], rescale_t 3.
  (`radiance_field` decoding skipped: it is not used by the GLB export and does not change the result.)
- `postprocessing_utils.to_glb(gaussian, mesh, simplify=0.95, texture_size=1024)` (defaults:
  hole filling on, texture baked from the Gaussians, `opt` mode).
- Output: the GLB TRELLIS writes is saved untouched as `intermediate/<key>/raw_trellis.glb`.

## Orientation (→ contract: Y-up, front +Z)
- TRELLIS `to_glb` output is already glTF Y-up. Checked with CPU renders of smoke-test assets
  (armchair, sofa, cabinet, cup, clock; `methods/embodiedgen_v2/preview.py`): seats/doors face **+Z**
  → method-wide rotation `front_rot_y_deg = 0`.
- **Thin-axis fix** (`rgbjob.align_thin_axis`, recorded per asset in the sidecar `orient_fix`):
  if the target bbox is clearly thin along one axis (min/2nd-min extent < 0.35) and the generated
  mesh is clearly thin along a *different* axis, rotate 90° so they coincide. Typical case: TRELLIS
  generates wall clocks / wall art lying face-up → rotated +90° about X so the face points +Z.
  Uses only the asset's own input bbox dimensions. The raw GLB is kept, so this can be undone.

## Outputs
- `assets/<asset_key>.glb` + `.json` sidecar (`status`, `prompt`, `seed`, `seconds`, `raw_glb`,
  `raw_extent_xyz`, `orient_fix`, `stats` = faces / texture sizes / extents, `host`, `slurm_job`).
- Faces are low (simplify=0.95 → typically 5k–30k faces), textures 1024².

## Commands
```bash
source bench/env.sh; conda activate rgb_embodiedgen
# local hala worker loop (GPU lock, <=19 min per invocation, resumable, claims via locks/):
nohup methods/trellis_text/run_loop.sh > logs/trellis_text_loop.log 2>&1 &
# one chunk by hand:
bench/gpu_run.sh python methods/trellis_text/gen_trellis_text.py --chunk 40
# backup SLURM GPU worker (no lock inside SLURM):
sbatch methods/trellis_text/slurm_worker.sbatch
# re-apply the GLB conversion from the raw outputs (CPU):
python methods/embodiedgen_v2/reconvert.py trellis_text 0
```

- **184 / 184 ok**, 0 fallback, 0 failed (2026-10-04).
- 179 assets were generated by the SLURM backup worker (job 1073779, H200 `sof1-h200-7`):
  median 13.5 s/asset (mean 16.7 s, incl. GLB baking); 5 smoke-test assets +
  1 retry on the shared hala A6000 under the GPU lock: median 85 s/asset (first asset includes
  the nvdiffrast JIT build). Pipeline load ~30–85 s per worker start.
